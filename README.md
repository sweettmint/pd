# Идентификация защитных маркеров ("водяных знаков") на прозрачной полимерной упаковке с помощью свёрточной нейронной сети

Проект выполнен в рамках выпускной квалификационной работы.

## Описание
Разработана свёрточная нейронная сеть для автоматической идентификации защитных элементов (маркеров в виде фигур животных), нанесённых на прозрачную полимерную плёнку и видимых только в поляризованном свете.

## Требования
- Python 3.8+
- TensorFlow 2.x
- Pillow (PIL)
- NumPy

pip install tensorflow numpy pillow
